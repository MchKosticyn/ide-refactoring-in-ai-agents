# План перемонтажа демо: три ролика по ≈ 60 с

Цель: каждый ролик не длиннее минуты, ключевые моменты в нормальной скорости с подписью, остальное ускорить или вырезать.
Таймкоды — по исходному `session.mp4` каждого прогона (как в `STORYLINES.md`). Для демо 1–2 это «время agg», для демо 3 — секунды исходника.

Общие правила:
- Без титулов и финальных карточек: только экран агента с подписями. Агент, модель и итоги уже на слайдах.
- «Нормальная скорость» = ×1, подпись 1–2 строки, держится всё время сегмента.
- «Пробежка» = ×3…×8 с пометкой «ускорено ×N», подпись одна на сегмент или без подписи.
- Не упоминаем: двойника `FormattingRule.lint`, разницу промптов (тесты), сравнение времени между подходами.
- Один и тот же эпизод во всех трёх демо (detekt нашёл длинную строку → правка) показываем только в демо 1, в остальных вырезаем.

## Что обязательно остаётся в каждом ролике

- Текст: падение и починка скрипта; rename по подстроке с комментарием; тесты без флага; отчёт с соседним модулем.
- LSP: «зачем LSP»; «24 changes»; сервер удалил импорт и откат; смена сигнатуры в протоколе отсутствует → скрипт.
- Движок: find_usages по ссылкам; два Rename с пробным прогоном и «0 конфликтов»; perl по временному имени.

Карта в `edit.py`: демо 1 — `SEGMENTS` по сырому времени cast (другая шкала, пересчитать через `rawR`), демо 2 — `SEGMENTS`/`CAPTIONS` во времени agg, демо 3 — `SEGMENTS`/`CAPS` в секундах исходника. Таймкоды выше — в шкале исходного `session.mp4`, как в `STORYLINES.md`.
