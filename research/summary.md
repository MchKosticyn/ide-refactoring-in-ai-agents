## Что подходит под план с митинга 2026-09-28

План требует: один кейс; Claude Code текстом — заметный провал или заметная цена; тот же кейс на LSP; тот же кейс на движке через Veai. Практические ограничения: Veai — IntelliJ-плагин; LSP-демо надёжно только на Java (jdtls); Kotlin LSP сырой; Spring XML — отдельная добавка.

**Рекомендация: Keycloak #49814, срез `LoginPage`/`AbstractPage` + `BrowserFlowTest`.**
- Java, Selenium page objects — код тестировщиков, зал узнаёт.
- Ловушки в одном методе: целевое имя занято с другим контрактом (`assertCurrent()` уже есть, 1408 вызовов); перегрузка `isCurrent(String)`; две несвязанные иерархии с одним именем (55 определений, менять ~48); `boolean → void` превращает 33 `assertFalse(page.isCurrent())` в инверсию — реально пойманы ревью в PR.
- LSP на Java работает; Change Signature / Rename в IntelliJ — конфликт «уже существует».
- Риск: модуль `integration-arquillian` в IntelliJ — тяжёлый импорт; проверить, что резолв page-классов работает без сборки SNAPSHOT.

**Альтернатива, если Android-окружение есть: Fenix.** Самая чистая механика «66 одинаковых строк — шесть разных методов», реальный баг (тест без assert годами зелёный). Но Kotlin (LSP слабый), Gradle sync с Android SDK, репо архивировано.

**Запасной, гарантированно воспроизводимый: detekt.** Kotlin, чистый Gradle; «имя занято, тесты зелёные». Меньше QA-релевантность (тестовый DSL авторов правил линтера).

Ни один кейс не содержит Spring XML — добавка Максима либо синтетическая, либо отпадает.

## Решение 2026-09-29

Keycloak отклонён: по коду на `471f2762` `assertCurrent()` уже был обёрткой над `isCurrent()`, PR — миграция с изменением поведения (новый механизм `data-page-id`), а не рефакторинг; операции движка для неё нет. Ограничение «только Java» снято (Veai работает в PyCharm/WebStorm). Воспроизведены detekt и CPython (`repro-2026-09-29.md`). **Выбран detekt** — единственный, где текст промахнулся на реальном коде (2 вызова без точки), LSP находит, движок даёт конфликт имени. Справка для демо — `demo-detekt.md`.
