## Что годится на слайд

1. **Codex CLI** (системный промпт, OpenAI): «When searching for text or files, prefer using `rg` … Do not use apply_patch … when scripting is more efficient (such as search and replacing a string across a codebase).» — массовая замена по кодовой базе = скрипт, не рефакторинг. Permalink: `codex-rs/core/gpt_5_codex_prompt.md#L5,L11` @ `8f65177`.

2. **Claude Code, bypass/auto-режим** (цитата из issues #88475/#90599/#89251): «…make file changes with `sed`, heredocs, or short scripts, rather than using the dedicated Read, Edit, or Write tools. Fall back to a dedicated tool only when Bash genuinely cannot do the job.» — Anthropic сама разворачивает модель к `sed`.

3. **Claude Code, официальная документация**: «On macOS, Linux, and WSL, Claude Code leaves Glob and Grep out of the default tool set, and Claude searches with `find` and `grep` through the Bash tool instead.» (tools-reference, «Glob tool behavior») + CHANGELOG 2.1.117. Сильный аргумент: даже «структурные» инструменты поиска заменены на шелл ради скорости.

4. **OpenCode, описание Edit**: «Use `replaceAll` for replacing and renaming strings across the file. This parameter is useful if you want to rename a variable for instance.» — переименование переменной = текстовая замена, хотя LSP в продукте есть (используется для диагностики после правки: «LSP errors detected in this file, please fix:»).

5. **Контраст — кто делает иначе.** Copilot CLI (docs.github.com): «Copilot CLI will use an LSP server rather than text-based search whenever it can access an LSP server … Rename — Renames a symbol across the entire project». JetBrains Junie: «This is the kind of refactoring that text-based search gets wrong.» Serena: «Those descriptions … are SUPERSEDED here.»

Возможный тезис слайда: у всех терминальных агентов единственный инструмент правки — exact-string replace / патч (Codex `apply_patch`, Claude Code `Edit`, Gemini `replace`, OpenCode `edit`, Cursor `search_replace`, Aider SEARCH/REPLACE); там, где LSP есть (Claude Code, OpenCode), он read-only или диагностика; rename через LSP/IDE — только у Copilot CLI, Junie и Serena.

## Что нельзя утверждать

- **Что Anthropic опубликовала текст bypass-блока.** В документации и CHANGELOG его нет; источник — issues пользователей с цитатами и `grep` по бинарю. В моём бинаре 2.1.197 строки нет, самостоятельно проверить в свежей версии я не мог. Формулировка для слайда: «цитата по issues anthropics/claude-code #88475, #90599 (авг. 2026), версии 2.1.228–2.1.251».
- **Что этот блок действует во всех режимах.** По #89251 — bypass и auto; #88041 упоминает гейт `bashFirst` в auto-режиме. В default/acceptEdits — не подтверждено.
- **Точный текст описаний Grep/Edit/Bash в Claude Code** — из строк бинаря 2.1.197 с подстановкой имён инструментов; в документации есть только краткие формулировки. Указывать как «tool description, Claude Code 2.1.197».
- **Промпты Cursor** — только утечка (x1xhlol, дата файла 2025-09-03); Cursor это не подтверждал. На слайде помечать «leaked, unverified». Официальная документация Cursor подтверждает лишь набор категорий инструментов.
- **Промпт Copilot CLI** — закрыт; утверждать можно только то, что в docs.github.com (LSP с Rename, серверы не в поставке). Файл `copilot-gpt-5.txt` в OpenCode как «промпт Copilot» — не подтверждено.
- **Промпт Junie** — закрыт; есть только блог и changelog плагина.
- **Что Codex/Gemini/Aider «не знают о LSP» вообще.** Верно только про промпты и код инструментов: в промптах и tool-спеках слово LSP отсутствует (Codex — ни в `.md`, ни в `.rs`; Gemini — только как список идентификаторов языков; Aider — tree-sitter для карты репозитория). Про MCP-расширения этих агентов это ничего не говорит.
- **Что OpenCode «не использует LSP».** Использует — для диагностики после правки (по умолчанию) и навигации (экспериментально). Не использует для rename/code actions.
- **Что Claude Code LSP «недоступен».** Доступен, но неактивен без плагина code-intelligence, read-only и без rename.
