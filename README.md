# Использование инструментов рефакторинга IDE в ИИ-агентах

Материалы доклада (40–45 мин): план, справка по демо-кейсу, исследования, заметки и скрипт сборки презентации.

- `План доклада.md` — краткий план.
- `План подробный.md` — подробный план: по каждому пункту что на слайде, что говорим, зачем, время; вопросы к организаторам; заготовки Q&A.
- `demo-detekt.md` — справка по демо-кейсу (detekt, PR #7873): воспроизведение, промпт, проверки, результаты прогонов.
- `research/` — исследования: поиск кейса (`summary.md`, `cases-*.md`), воспроизведение (`repro-2026-09-29.md`), ограничения LSP по спецификации (`lsp-limitations.md`), промпты агентов (`agent-prompts-terminal.md`).
- `notes-lsp-vs-psi.md` — проверенные факты для слайдов: LSP, PSI, движок IntelliJ, MCP.
- `build_deck.py` — сборка `.pptx` поверх фирменного шаблона Veai (`python3 build_deck.py`). Шаблон в репозиторий не входит; путь задаётся переменной `VEAI_TEMPLATE`.
- `Доклад_ Рефакторинг в ИИ-агентах.pptx` — собранная презентация.
